# Agent Operational Protocols: Twitch Room

This document defines the expected behavior and tool-use protocols for AI agents working in this repository. 

## Tool Usage Hierarchy
1. **Direct Tool Priority**: Always use dedicated tools (`shell`, `read`, `write`, `grep`, `glob`, `edit`) directly. 
2. **Minimal `execute` usage**: The `execute` tool (JavaScript runtime) should ONLY be used for:
    - Orchestrating complex, parallel tool calls via `Promise.all`.
    - Complex data processing/transformation of tool outputs.
    - Logic that cannot be expressed via standard tool parameters.
3. **Never "Double-Wrap" Tools**: 
    - **CORRECT**: `shell({ command: '...' })`
    - **INCORRECT**: `tools.shell.execute({ command: '...' })`
4. **Runtime Awareness**: Assume that the `execute` tool's environment is restricted. Do not assume all top-level tools are available inside the `execute` JavaScript context unless verified.

## Communication & Execution
- **Contextual Verification**: Before executing a complex multi-step plan, verify the current workspace structure and file existence.
- **Error Recovery**: If a tool call fails with a "name error" or "type error," immediately halt, analyze the tool catalog, and correct the syntax before retrying.
